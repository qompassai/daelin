# Muse + LinkedIn Learning skills

Skills for using Muse as the study system around LinkedIn Learning:
the service supplies the lectures; these skills supply selection,
notes, drills, and progress memory.

| Skill | What it covers |
|---|---|
| `muse-linkedin-learning` | Goal → course shortlist, course → mechanism-level study notes, notes → flashcards/self-quizzes/worked exercises, and a per-track progress tracker. |

Workflow skills authored for Matt (LinkedIn Learning offers no
personal-account API): course playback, enrollment, and in-service
progress stay in the user's own browser; Muse works from course pages,
syllabi, and material shared in-session.
